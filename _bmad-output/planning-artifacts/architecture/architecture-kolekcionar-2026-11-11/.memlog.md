- (constraint) Backend must be async FastAPI (Python)
- (constraint) Database must be PostgreSQL
- (constraint) Hosting on Railway platform
- (constraint) Frontend must be a JavaScript framework or toolchain supporting Web, Android, and iOS from unified codebase
- (decision) Frontend: React Native with Expo (Expo Router) for universal Web, iOS, and Android support from a unified TypeScript codebase.
- (decision) Repository structure: Turborepo Monorepo containing Public App (Expo), Admin Console (Next.js/React Web), and shared API contracts.
- (decision) Queue & Workers: Redis on Railway as message broker paired with Taskiq / ARQ async Python workers for Scraping, AI Curation, and Verification queues.
- (decision) Storage & CDN: Cloudflare R2 (S3-compatible object storage) with pre-signed client uploads and Cloudflare Edge CDN.
- (decision) AI Engine execution: Hybrid architecture with lightweight local libraries (ImageHash pHash + ONNX CLIP ViT-B/32) for fast deduplication, and vision LLM APIs (Gemini/OpenAI) for condition estimation.
- (decision) Scraper architecture: Cloud-based worker pool consuming from Redis Scraping Queue, with dedicated scraper types: Fandom wiki extractor, eBay API price benchmark tracker, change detection crawler, and image downloader pushing to Cloudflare R2.
- (decision) AI Curation Pipeline: Two-pass agent architecture (Ingestion Normalizer Agent + Verification Critic Agent) to clean, normalize into 3-tier MDM schema, and validate scraped data before routing to Admin Verification Queue.
- (decision) Backend Stack: FastAPI async with SQLAlchemy 2.0 (asyncpg), Alembic migrations, PostgreSQL 16 with pgvector and pg_trgm extensions.
- (decision) Auth & Verification: JWT access/refresh tokens (SecureStore on mobile, httpOnly cookie on web) with Infobip SMS verification for Serbian (+381) phone numbers.
- (event) spine finalized
